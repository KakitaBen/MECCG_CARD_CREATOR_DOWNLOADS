# MECCG Card Creator — Téléchargements

Créez vos cartes MECCG, composez vos decks et préparez votre collection à
l’impression, en français ou en anglais.

**[Choisir ma version et télécharger l’application](https://meccg-card-creator-downloads.kakitaben.chatgpt.site)**

Une version de test complète est disponible pour les trois systèmes.
La page de téléchargement propose la version publiée la plus récente ; consultez
les [notes de version](https://github.com/KakitaBen/MECCG_CARD_CREATOR_DOWNLOADS/releases).

| Ordinateur | Fichier |
| --- | --- |
| Windows 64 bits, Intel/AMD | `MECCG-Setup-Win64.exe` |
| macOS, Intel ou Apple Silicon | `MECCG-Installer.pkg` |
| Linux 64 bits, Ubuntu/Debian, base Ubuntu 22.04 minimum | `MECCG-Linux64.deb` |

À la première ouverture, le lanceur télécharge automatiquement les images,
les polices et le moteur de rendu Inkscape : environ 3 Go de ressources, plus
le programme. Prévoyez une connexion Internet et 8 Go libres pendant
l’installation. Un téléchargement interrompu peut reprendre. Ensuite,
l’application fonctionne hors connexion.

Les fichiers personnels modifiés, dont le classeur des cartes, sont conservés
lors des mises à jour. Les installateurs Mac de validation ne sont pas encore
signés et notarisés pour une diffusion générale.

Ce dépôt public héberge les téléchargements et leurs notes de version. Aucun
compte GitHub n’est nécessaire pour accéder aux releases publiées. Les
fichiers `manifest.json` et `*.tar.gz` sont utilisés automatiquement par le
lanceur : l’utilisateur télécharge uniquement le fichier de son système.

Pour la maintenance : [fabrication avec les machines publiques gratuites](BUILDING.md).
